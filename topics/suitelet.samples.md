Suitelet example code falls into four groups, each with its own page:

| Group | What the samples show |
|---|---|
| [Basics](suitelet.samples.basics.md) | Assistants, pages with embedded HTML, linking a Suitelet from a record, returning XML |
| [Custom forms](suitelet.samples.forms.md) | serverWidget forms: field types, tabs, buttons, sublists, email, dates, secret and credential fields |
| [Custom lists](suitelet.samples.lists.md) | Stand-alone list pages, plus a dashboard-icon column built with a custom field |
| [Backend Suitelets](suitelet.samples.backend.md) | Suitelets that return data, files or redirects instead of a page |

All examples on these pages are written for SuiteScript 2.1 and use invented business scenarios.
They are entry-point scripts, so they are wrapped in `define`; when you paste one into the debugger,
switch to `require` (see [Basic Suitelet Samples](suitelet.samples.basics.md)).
