# Support records
<!-- id: topic:records_guide.support -->

Part of: [SuiteScript records guide](records_guide.md)

Support records cover customer service cases and the issue-tracking and knowledge-base data around
them.

## Record types in this group

| Record ID | Reference page |
|---|---|
| `supportcase` | [supportcase](../gen/records/supportcase.md) |
| `issue` | [issue](../gen/records/issue.md) |
| `issueproduct` | [issueproduct](../gen/records/issueproduct.md) |
| `productversion` | [productversion](../gen/records/productversion.md) |
| `solution` | [solution](../gen/records/solution.md) |
| `topic` | [topic](../gen/records/topic.md) |

The spec lists only the members of this group; it gives no group-wide rules. Per-record field IDs
are on the linked pages, and channel support is in the
[SuiteCloud record support catalog](../gen/catalogs/suitecloud_record_support.md).
