# Website records
<!-- id: topic:records_guide.website -->

Part of: [SuiteScript records guide](records_guide.md)

Website records describe web store content: sites, their categories, content-management pages and
content, and shopping carts.

## Record types in this group

| Record ID | Reference page |
|---|---|
| `cmscontent` | [cmscontent](../gen/records/cmscontent.md) |
| `cmscontenttype` | [cmscontenttype](../gen/records/cmscontenttype.md) |
| `cmspage` | [cmspage](../gen/records/cmspage.md) |
| `commercecategory` | [commercecategory](../gen/records/commercecategory.md) |
| `website` | [website](../gen/records/website.md) |
| `shoppingcart` | [shoppingcart](../gen/records/shoppingcart.md) |
| `sitecategory` | [sitecategory](../gen/records/sitecategory.md) |

The spec states only the membership of this group. See each record page for its fields and the
[SuiteCloud record support catalog](../gen/catalogs/suitecloud_record_support.md) for the channels
that can reach it.
